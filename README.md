## 2. Software & Operating Systems Analysis

### 1. Vertical vs Horizontal Software
- Vertical: Epic EHR, Toast POS - built for one specific industry
- Horizontal: Excel, Slack, Google Workspace - built for all industries

### 2. Batch vs Real-Time Processing
- Batch: Data processed in groups later. Ex: Payroll, bank statements.
- Real-Time: Data processed instantly. Ex: ATM, stock trading.
